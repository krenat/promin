# Promin

Домашній відеосервер для проектора: завантажуєте відео з телефона, сервер перекодовує його у формат, який проектор грає без буферизації, а телефон стає пультом.

**Стан:** у розробці. Уже працює завантаження, перекодування через ffmpeg, список, перегляд у браузері та видалення. Пульт і вхід за токеном ще не додані, тому сервіс поки не можна відкривати в інтернет.

## Що буде в першій версії

- завантаження відео з телефона через браузер;
- автоматичне перекодування через ffmpeg у 1080p H.264;
- сторінка `/tv` для браузера проектора і сторінка `/` для телефона;
- керування відтворенням на проекторі з телефона через WebSocket;
- вхід за токеном.

## Стек

Python 3.12, FastAPI, Uvicorn, ffmpeg, Docker.

## Запуск локально

Потрібні Python 3.9+ і ffmpeg з ffprobe у `PATH`. Для коректних кольорів HDR-відео ffmpeg має бути зібраний з libzimg (фільтр `zscale`), як у Debian та Ubuntu.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python main.py
```

Сторінка відкриється на `http://localhost:8080`. Тести: `.venv/bin/python -m pytest`.

## Налаштування

Усі налаштування задаються змінними середовища, приклад і опис — у `.env.example`. Токен поки не використовується: вхід з'явиться на одному з наступних етапів.

## Як обробляється відео

- Файл, який уже є H.264 8 біт SDR, вписується в 1920×1080, має до 60 кадрів/с і помірний бітрейт, лише перепаковується з `+faststart`.
- Усе інше перекодовується в H.264 High 1080p з обмеженням бітрейту, ключовим кадром кожні 2 секунди і звуком AAC; HDR переводиться в SDR.
- Метадані оригіналу (зокрема геолокація) у готовий файл не потрапляють.
- Оригінал видаляється після успішної обробки.
